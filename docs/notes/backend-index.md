# Backend index and API: notes (Phase 2)

- Spec: `packages/shared/spec.md` v2 (frozen). API is `GET /api/invoices`, `GET /api/invoices/:id`, `POST /api/invoices`, `GET /api/audit`, `POST /api/approvals`, `GET /api/world/callback`, `GET /api/approvals/:id`. Older prompts mention `/api/agent`, `/api/payments`, `/api/agents/:vault`, `/api/events`; those are NOT in spec v2 and were not built. Ask Nisarg before adding endpoints.
- Tables (`services/backend/src/db.ts`, append-only migrations): `invoices`, `events` (unique tx_hash + log_index), `approvals`, `meta`. Every invoice and event row has `source` = `chain` or `seed`. The API has no `source` field (the shared Invoice schema is frozen), so seed rows carry "DEMO" at the start of `description`.
- Indexer (`src/indexer.ts`): polls every 5 s (`createIndexer(...).start()`), reads from (last block - 4) to the head in chunks of `maxRange` (default 1000, Hedera RPC getLogs limit UNVERIFIED), dedupes by tx hash + log index, retries each read 3 times, saves progress only after a full successful poll, exposes `getLastSyncedAt(db)`. Only `InvoiceFunded(uint256 indexed id, address indexed holder, uint256 faceAmount)` is frozen; for any log whose first indexed topic is an invoice id the indexer stores the event and refreshes the invoice with `getInvoice(id)`. It never overwrites `seed` rows or the off-chain description.
- Chain reader (`src/chain/reader.ts`): viem on Hedera testnet (chain 296, RPC https://testnet.hashio.io/api); the `getInvoice` struct ABI follows the spec and is UNVERIFIED until Mann deploys InvoiceMarket. The server starts the indexer only when `INVOICE_MARKET_ADDRESS` is set.
- Score (`src/score.ts`): New (< 3 settled), A (>= 95% on time), B (80 to 94), C (< 80). A Late invoice that is later Paid counts as on time (the Status enum loses that history).
- Seed: `SEED=1 bunx tsx scripts/seed.ts` inserts 6 DEMO rows (ids 9000001 to 9000006); `removeSeed` deletes only `source = 'seed'` rows.
- Bun gotcha: `better-sqlite3` crashes Bun 1.3.14 (NAPI fatal error). Run anything that opens the database with Node (`tsx`, `vitest`), not `bun file.ts`.
- Not done: Hedera mirror-node polling (no payments table in spec v2; x402 payments belong to Mann's paid API), Gate 2 (a real invoice indexed end to end needs Mann's deployed InvoiceMarket).
